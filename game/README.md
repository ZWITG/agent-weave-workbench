# Relivable

A life simulator where every choice is remembered. Live a whole life one
year at a time: school, love, work, money, crime and prison, fame, the very
top of the rich list, family and the generations after you.

## Install

Every build is published to the rolling
[`relivable-latest`](https://github.com/ZWITG/agent-weave-workbench/releases/tag/relivable-latest)
release by `.github/workflows/relivable.yml`, after the full test suite
passes.

| Device | How |
| --- | --- |
| Android | Download `Relivable.apk` and open it. Installed copies update themselves. |
| iPhone / iPad (easiest) | Open <https://zwitg.github.io/agent-weave-workbench/> in Safari, tap Share, then Add to Home Screen. Always the latest version. |
| iPhone with AltStore / SideStore | Add the source `https://github.com/ZWITG/agent-weave-workbench/releases/download/relivable-latest/altstore.json` in the store app, then install. |
| Windows | Download `RelivableSetup.exe` and run it, or unzip `Relivable-portable.zip`. |
| Web | <https://zwitg.github.io/agent-weave-workbench/> |

Versions are `1.0.<build>`; apps compare the build number to offer updates.
Named updates are listed in [CHANGELOG.md](CHANGELOG.md).

## Develop

```sh
flutter pub get
flutter analyze
flutter test          # engine, 500-life simulator, fuzz, small-phone UI
flutter run           # or: flutter build web / apk / windows
```

- `lib/engine/` holds the game rules (no Flutter imports): one file per
  system, wired together in `engine.dart` (each birthday), `scenes.dart`
  (story scenes), `actions.dart` (activities) and `variants.dart` (ways to
  do them).
- `lib/ui/` holds the screens. The look follows the life: Night Feed,
  Yard Time in prison and Gilded in the upper echelon (`theme.dart`), with
  takeover animations in `lockdown.dart` and `invitation.dart`.
- `tool/` has render scripts for visual checks
  (`flutter test tool/render_lockdown_test.dart --dart-define=OUT=<dir>`)
  and the sound generator.

Fonts are under the SIL Open Font License (`assets/fonts/OFL.txt`); all
sound effects are generated by `tool/make_sounds.py`.
