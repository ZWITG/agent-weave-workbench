# Relivable — "Calling" reel style

Source: two reference reels uploaded by the user, `reel_calling.mp4` and
`reel_calling_1.mp4` (12–14s each), showing the house style for Relivable
(the life-sim game, formerly pitched as a BitLife-style app) social ads.
First built into an artifact ad for the "Second Acts" update:
https://claude.ai/artifact/PccPiVGs8oXyh9koqMndT3 (reference for the shape,
not to be reused verbatim — each ad gets its own phone content).

This is the default style for any Relivable ad unless the user asks for
something else. Do not substitute a generic Instagram-post template (black
background, neon grid, logo-text header) — that was tried once and
rejected; it is NOT the Relivable style.

## Format

- Vertical frames, 1080×1350 aspect ratio, one frame per beat.
- A reel is a short sequence of these frames (3–5), each a hook, a payoff,
  or more hooks, ending on one closing/CTA frame. For a static ad, one
  frame is enough; for a short ad, build a swipeable/scrollable carousel
  of frames rather than cramming everything onto one.

## Per-frame layout (hook/payoff frames)

Top to bottom:
1. **Eyebrow tag**, top-left: small, bold, uppercase, letter-spaced,
   colored to the frame's accent (e.g. `FLOODLIGHTS`, `FIGHT NIGHT · NEW`,
   `MARQUEE`). Names the in-game moment or marks it `· NEW`.
2. **Wordmark**, top-right, same row: `RELIVABLE` (or later `R RELIVABLE`
   lockup), small, bold, uppercase, letter-spaced, muted/low-opacity —
   never competing with the eyebrow or headline.
3. **Headline**: one or two words, serif display face (heavy weight,
   Playfair-Display-like), large, tight line-height, ends in a period
   (`Fighter.`, `Athlete.`, `Pick a job.`). This is the whole ad's voice —
   blunt, declarative, never a tagline sentence.
4. **Phone mockup**, bottom half to two-thirds of the frame: a real
   screenshot (or a faithful recreation) of the actual in-game UI for that
   moment, inside a rounded device frame, tilted a few degrees for energy.
   Shows real game chrome: back arrow, a themed eyebrow/title inside the
   card, a stat or outcome, choice buttons or a Continue button. This must
   look like the real app, not an abstract icon grid.

## Color: one theme per career/moment

Each frame gets its own full-bleed radial/gradient background and accent
color tied to the career or moment it shows — not one fixed brand palette
reused everywhere:

- Actor / theatre: deep maroon → near-black gradient, gold accent.
- Athlete / sport: dark green → near-black gradient, lime/acid-green accent.
- Fighter / combat: dark red → near-black gradient, yellow/teal accent.
- Pick a new accent per career in the same family (deep saturated color
  fading to near-black) when adding others — politician, pilot, model,
  etc. each get their own, never reuse another career's color for a
  different one.

Background pattern: a soft radial glow from the upper-left, fading to
near-black at the edges and bottom. Not flat, not a grid pattern.

## Closing/CTA frame

Different structure from the hook/payoff frames:
- Background: a dimmed/darkened collage of many career screens (mock this
  with a faded repeating pattern or stacked ghosted cards if a real
  collage isn't available), near-black overlay so text stays legible.
- Big serif headline, 2 lines, white with one accent-colored word/line
  (e.g. "Which one / **are you?**").
- Subhead: short stat line, lowercase-ish, mid-grey (`14 careers · one
  life · free`).
- CTA pill: solid warm accent (amber/orange), dark text, rounded-full,
  bold (`Play free · link in bio`).
- Footer: small circular "R" logomark + `RELIVABLE` wordmark, then a
  muted platform line (`Free · Android, iPhone, Windows & web`).

## Typography

- Display/headline: a bold serif (Playfair Display or equivalent) —
  carries the voice, used nowhere else on the frame.
- UI/body (eyebrow, phone mockup, CTA, footer): a rounded, friendly
  sans-serif (Baloo 2 or equivalent) — distinct from the headline face,
  never serif.

## Things to not do

- Don't default to a flat black background with a neon grid and a bold
  condensed logo-text header — that's a different brand's style (ZWITG),
  not Relivable's.
- Don't skip the phone mockup — an ad with just type and no in-game screen
  is missing the thing that sells the feature.
- Don't reuse one accent color across every frame of a multi-frame ad;
  each career/moment carries its own.
