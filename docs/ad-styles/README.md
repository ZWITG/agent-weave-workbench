# Ad style guide

One file per game/brand of ad we've built, so a style never has to be
re-derived from a screenshot again. AGENTS.md points here — read the
matching file before building any ad, reel frame, or social post, and
match it exactly unless the user asks for something new. When the user
shows a new reference (video, image, or artifact) for a game or a new
style, add a file here for it before building anything, the same way
`relivable.md` was built from the "Calling" reel videos.

- [`relivable.md`](./relivable.md) — Relivable ("Calling" reel style)
